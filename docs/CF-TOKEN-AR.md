# إنشاء توكن Cloudflare صحيح — خطوة بخطوة

> **الهدف:** توكن يغطي كل احتياجات الموقع (رفع، نطاق جديد، DNS، شهادات)
> **بلا** منحه سيطرة على كل شيء إلى الأبد.

---

## الرابط

```
https://dash.cloudflare.com/profile/api-tokens
```

---

## لماذا توكن مخصص وليس Global API Key

| | توكن مخصص ✅ | Global API Key ❌ |
|---|---|---|
| الصلاحيات | تحدّدها بدقة | **كل شيء، بلا استثناء** |
| قابلية التقييد | بنطاق أو حساب معيّن | لا |
| الإلغاء | زر واحد، فوري | يلزم تغيير كلمة المرور |
| يصلح لهذا المشروع | نعم | زيادة خطيرة بلا فائدة |

**الصلاحيات الكاملة ليست أمانًا أكثر — هي خطر أكبر بلا مقابل.**
التوكن المخصص يعطينا 100% مما نحتاجه.

## الخطوات

| # | الخطوة |
|---|--------|
| 1 | افتح الرابط أعلاه |
| 2 | اضغط **Create Token** |
| 3 | انزل للأسفل ← **Create Custom Token** ← **Get started** |
| 4 | **Token name**: `rawaa-deploy-full` |
| 5 | **Permissions** ← أضف الصفوف من الجدول أدناه |
| 6 | **Account Resources** ← Include ← اختر حسابك `ghith.shikhkhaled@gmail.com` |
| 7 | **Zone Resources** ← Include ← **All zones from an account** ← نفس الحساب |
| 8 | **TTL** ← اتركه **No expiry** |
| 9 | **Continue to summary** ← **Create Token** |
| 10 | **انسخ التوكن الآن** — يظهر مرة واحدة فقط |

> ⚠️ **أهم سطر في الدليل: الخطوة 7.**
> لو اخترت «Specific zone» لن يشمل التوكن النطاق الجديد `rawaa.eu.org`
> لأنه غير موجود بعد. يجب أن يكون **All zones from an account**.

## الصق التوكن هنا

بعد النسخ، الصقه في المحادثة كرسالة واحدة. سأفعل به ما يلي:

| نعم ✅ | لا ❌ |
|--------|-------|
| أضعه في متغيّر بيئة لسطر واحد | أكتبه في أي ملف |
| أتحقق منه فورًا | أضعه في git أو log |
| أستخدمه ثم أزيله من البيئة | أطبعه في أي تقرير |
| أختبر صلاحياته وأخبرك بالنتيجة | أشاركه مع أي خدمة أخرى |

### التحقق الذي سأجريه
```bash
wranger whoami                                  # الهوية والحساب
GET  /accounts/{id}/workers/scripts             # قراءة العمال
POST /zones                                     # إنشاء النطاق
```
ثلاثة اختبارات: الهوية، النشر، وإنشاء النطاق — وهي التي فشلت اليوم.

## إن أردت الأبسط

بدل 9 صلاحيات، ثلاث فقط تكفي للبدء:

```
Account → Workers Scripts → Edit
Zone    → Zone            → Edit
Zone    → DNS             → Edit
```

هذه الثلاث هي الحد الأدنى الذي ينقلنا من «لا أستطيع إنشاء نطاق» إلى
«الموقع يعمل على `rawaa.eu.org`». الباقي يُضاف عند الحاجة.
