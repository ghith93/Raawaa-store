# مكتب تسويق رواء — محلي

واجهة عمل أولية للمسودات ووسوم الروابط وقراءة أرقام مجمّعة، وبها رابط إلى معاينة نموذج الطلب والموافقات. ليست لوحة تشغيل منشورة، ولا تتصل بمنصات النشر أو Meta/Google أو WhatsApp أو قاعدة بيانات.

## معاينة محلية

من جذر المشروع:

```sh
python3 scripts/marketing-studio-preview.py
```

يفتح الخادم على `http://localhost:4173/` ويوجه إلى الواجهة. يعرض ملفات محددة بقائمة سماح فقط؛ بقية المسارات ومنها `.git` وملفات البيئة تعيد 404. لا تستخدم خادم مجلد عام للمشروع. لإيقافه أوقف عملية المعاينة.

## ما تفعله الواجهة

- تعرض أربع **مسودات فقط** مع الإفصاح عن التصورات البصرية، وتشتق الأسعار مباشرة من `js/config.js`.
- تنشئ رابط `/campaign` بوسوم UTM من قائمة محددة. وسم `size_guide` معطّل لأنه لا يعمل على النسخة العامة الحالية حتى اعتماد ونشر تحديث منفصل. لا ترسل الأداة الرابط تلقائيًا ولا يثبت الوسم أن زيارةً تحولت إلى بيع.
- تحفظ أعدادًا غير شخصية اختياريًا في `localStorage` على المتصفح والجهاز الحاليين فقط، وتتيح تصدير CSV أو مسح السجل. لا تضع أسماء أو أرقام هواتف أو عناوين أو نص محادثة في هذه الأرقام.
- رابط معاينة الحملة يفتح الصفحة العامة الحالية؛ لا ينشر مسودة أو يغيرها.

## حدود الاستخدام

لا يوجد جدولة/نشر، حسابات اجتماعية مرتبطة، إرسال رسائل، تتبع جديد، مزامنة، أو إسناد موثوق للمبيعات. هذه النسخة لا تسجل موافقة تسويقية ولا تدير الانسحاب منها؛ لذلك لا تستخدمها لإرسال حملات أو قوائم عملاء. لا تُعامل الأرقام اليدوية أو المسودات كدليل على نتائج أو كأنها محتوى معتمد. راجع `.agents/skills/rawaa-content-workflow/SKILL.md` وحقائق `js/config.js` قبل اعتماد أي نص.

## الاختبارات

```sh
npm run test:marketing
```

تشغّل اختبارات وحدة بأدوات Node المدمجة (`vm` و`node:test`)، دون تثبيت حزم.
