## موجز الصورة التجريدية

- **القناة المقترحة:** منشور عضوي عمودي 4:5، لا إعلان مدفوع.
- **الفكرة:** حركة وانسياب بصري مجرّد ضمن لوحة رواء الدافئة، دون تجسيد ادعاء عن الشعر أو أداء المنتج.
- **الحالة:** `draft`؛ لم تُنشر ولم تُرفع إلى خدمة خارجية.
- **النص البديل:** «شرائط فنية بنية منحنية على خلفية عاجية دافئة؛ تصور بصري تجريدي مولّد لا يعرض المنتج أو الشعر.»
- **مراجعة الحقوق:** الأصل مولّد، ولا يتضمن شعارًا أو وجهًا أو عبوة أو أصلًا فوتوغرافيًا لشخص. تظل مراجعة شروط المنصة والملكية المحلية قبل الاستخدام مسؤولية المالك.
