## 1. المراجعة من iPhone (بدون نشر عام)

### الطريقة أ — شبكة محلية (الأسرع، بلا إنترنت)

على الحاسوب داخل المجلد:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

ثم اعرف عنوان الحاسوب في الشبكة:

```bash
# macOS / Linux
ipconfig getifaddr en0    # macOS
hostname -I               # Linux
# Windows
ipconfig                  # ابحث عن IPv4 Address
```

على iPhone — بشرط أن يكون على **نفس شبكة Wi-Fi** — افتح Safari:

```
http://<عنوان-الحاسوب>:8080/index.html
```

مثال: `http://192.168.1.20:8080/index.html`

لإضافة الموقع إلى الشاشة الرئيسية: زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

### الطريقة ب — أرشيف ZIP للمراجعة دون خادم

```bash
zip -r rawaa-storefront.zip index.html privacy.html robots.txt css js assets -x "assets/img/design-raw/*"
```

ملاحظة: فتح `index.html` مباشرة من نظام الملفات (`file://`) يعمل في الغالب، لكن بعض
المتصفحات تمنع تحميل الخطوط والصور عبر `file://`. الطريقة (أ) أدق.

### الطريقة ج — معاينة خاصة غير عامة (عند الحاجة)

يمكن استخدام استضافة ثابتة **بعد موافقتك**، مع حماية بكلمة مرور إن كانت الخدمة تدعمها.
لا نُنشئ أي رابط عام ولا نشتري خدمة.

## 2. تشغيل الفحوصات محليًا

```bash
# فحص بناء JavaScript
node --check js/config.js
node --check js/cart.js

# الفحص الآلي (187 فحصًا: ملفات، أسعار، روابط، ادعاءات، أصول)
node scripts/check-site.mjs

# اختبار المتصفح الفعلي (74 فحصًا) — يحتاج تثبيتًا لمرة واحدة
pip install playwright && python3 -m playwright install chromium
python3 -m http.server 8080 &        # يجب أن يكون الخادم يعمل
python3 scripts/browser-test.py
```

## 3. إعادة بناء الأصول (عند تعديل التصميم)

كل الأصول **مولّدة من كود**، فلا حاجة إلى تحرير صور يدويًا:

```bash
pip install pillow numpy uharfbuzz fonttools brotli freetype-py playwright

cd scripts
python3 brand.py            # اللوجو + العبوة المتجهة + لوحة الهوية (SVG)
python3 compose.py          # المشاهد التركيبية (SVG)
cd ..
python3 scripts/compose_photo.py    # تركيب العبوة على خلفيات الخامات (PNG أصلي)
python3 scripts/optimize_images.py  # AVIF/WebP/JPEG بأحجام متعددة
```

لتغيير الألوان أو نسب العبوة: `scripts/brand.py` (قاموس `C` للألوان و`SPECS` للأبعاد).
لتغيير الأسعار أو رقم واتساب: `js/config.js` فقط.

## 4. النشر لاحقًا (بعد موافقتك فقط)

الموقع **ثابت بالكامل**: لا خادم، لا قاعدة بيانات، لا متغيرات بيئة، لا أسرار.

### خيار 1 — GitHub Pages (مجاني)

1. ادفع الفرع إلى المستودع.
2. Settings ← Pages ← Branch: اختر الفرع والمجلد `/ (root)`.
3. لا يحتاج أي إعداد إضافي (كل الروابط نسبية).

### خيار 2 — Netlify / Cloudflare Pages / Vercel (خطة مجانية)

- Build command: **اتركه فارغًا**
- Publish directory: `/` (جذر المستودع)

### خيار 3 — استضافة عادية (cPanel / FTP)

ارفع فقط:

```
index.html
privacy.html
robots.txt
css/
js/
assets/            (بدون assets/img/design-raw وبدون assets/img/bottles — غير لازمة للنشر)
```

الملفات التي **لا** تُنشر: `docs/`, `scripts/`, `.github/` (و`robots.txt` يمنع فهرستها إن رُفعت).

### ما يجب فعله قبل النشر

- [ ] تأكيد الأسعار النهائية.
- [ ] تأكيد أن رقم واتساب يعمل.
- [ ] تعديل `og:image` و`canonical` إلى النطاق الفعلي.
- [ ] إنشاء `sitemap.xml` بالنطاق النهائي.
- [ ] مراجعة سياسة الخصوصية.
- [ ] استبدال التصورات بصور المنتج الحقيقية عند توفرها.

## 5. تعديل المحتوى لاحقًا

| ما تريد تغييره | الملف |
|---|---|
| الأسعار، رقم واتساب، أسماء الأحجام | `js/config.js` |
| نصوص الصفحة، الأسئلة الشائعة | `index.html` |
| سياسة الخصوصية | `privacy.html` |
| الألوان، المسافات، الخطوط | `css/styles.css` |
| سلوك السلة والرسالة | `js/cart.js` |
| التصميم البصري للعبوة واللوجو | `scripts/brand.py` |

بعد أي تعديل على الأسعار: `node scripts/check-site.mjs` للتأكد من عدم تعارض القيم.

## 6. ما لا يحتاجه المشروع

- ❌ قاعدة بيانات · ❌ خادم · ❌ خدمة دفع · ❌ اشتراك · ❌ مفاتيح API
- ❌ أدوات تحليل أو تتبع · ❌ خطوط أو صور من خوادم خارجية

الاعتمادية الوحيدة في وقت التشغيل: **المتصفح** + رابط واتساب عند الطلب.
