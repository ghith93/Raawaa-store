# خطوات تخص المالك — ما يتطلب معلومة أو تحققًا خارج المستودع

> **تحديث: 1 نوفمبر 2026.** ابدأ من [`../PROJECT-ROADMAP-AR.md`](../PROJECT-ROADMAP-AR.md) للحالة الحالية. لا تُنفّذ خطوة تجارية أو تغييرًا في الأسعار بسبب هذا الملف وحده.

## 1) التحقق من قناة واتساب — أعلى تحقق يدوي

الموقع يجهز مسودة فقط؛ الاختبارات لا تثبت أن الرقم يستقبل الرسائل. إذا رغبت، تحقق بنفسك من حساب الرقم بأن ترسل رسالة اختبار إلى جهة تختارها، ثم أبلغني بكلمة «يعمل» أو «لا يعمل» فقط. لا حاجة لإرسال نص الرسالة أو رقم الشخص أو لقطة شاشة. لن أرسل رسائل أو أتواصل مع العملاء نيابةً عنك.

## 2) تأكيد معلومات المنتج عند الحاجة إلى نشرها

تظل ادعاءات التركيبة والتحذيرات والتوفر والتغليف مقيدة بما يؤكده المصنع أو المالك. قبل تعديل المحتوى، يلزم مصدر مكتوب معتمد للمكونات النهائية والتحذيرات وأي بيانات نظامية ذات صلة؛ لا أخمّن INCI أو نسبًا أو شهادات أو أبعاد عبوة. لا أطلب صورة للعبوة، والتصورات المنشورة يجب أن تبقى موسومة بأنها تصورات تصميمية.

## 3) شروط البيع والتكاليف

لا توجد في هذا الملف مهلة أو رسوم أو شروط إرجاع مفترضة. إذا أردت نشر سياسة، زوّدني بنص الشروط المعتمدة كما تقررها أنت وبعد المراجعة اللازمة. أي تكلفة مصنع أو تغليف أو توصيل تستخدم في حساب الربحية يجب أن تكون رقمًا حقيقيًا ومصدره واضحًا؛ لا تغيّر الأسعار المرجعية أو الرسوم دون قرار صريح.

## 4) بيانات الدخول والأسرار

لا ترسل في المحادثة أو المستودع كلمات مرور أو توكنات أو مفاتيح API أو قيم أسرار GitHub/Cloudflare/Supabase. لا أحتاجها لتحديث الكود أو مراجعة الحالة. أدخل أي سر بنفسك في لوحة المزود الرسمية عند وجود إجراء محدد ومصرّح به، واكتفِ بإبلاغي أن الإعداد اكتمل دون كشف القيمة. لا تنشئ توكنًا جديدًا لمجرد هذا الملف.

## 5) الاستقبال الآلي للطلبات

لا حاجة لإجراء الآن. endpoint العميل غير منشور، وmigration 005 مرشحة محليًا فقط، ولا يوجد هدف staging معزول مؤهل. لا تُنشئ مشروعًا أو فرعًا مدفوعًا لتجاوز شرط الخطة، ولا تستخدم قاعدة مشتركة للاختبار. لن أفعّل استقبالًا أو تخزينًا أو رسائل قبل تحقق البيئة المعزولة ومراجعة الخصوصية والتراجع واختبارات بيانات اصطناعية.

## 6) تنبيه اعتماديات التطوير

أظهر GitHub تنبيهًا متوسطًا واحدًا، لكن صلاحية قراءة تفاصيل Dependabot عبر API غير متاحة في هذه الجلسة. فحص الإنتاج المحلي `npm audit --omit=dev` وجد صفر ثغرات؛ لن أطبّق ترقية قسرية أو override يكسر توافق الأدوات. إذا راجعت التنبيه من تبويب Security، يكفي إرسال اسم الحزمة ومعرّف النشرة العامة فقط؛ لا ترسل أي معلومات حساب أو أسرار.

## ما لا أطلبه

لا أطلب صورة منتج أو عبوة، ولا بيانات عميلات أو محادثات خاصة، ولا مراسلة مصنع أو شركة توصيل نيابةً عني، ولا دفعًا أو إعلانًا، ولا إعدادًا مدفوعًا. تبقى هذه القائمة مرجعًا للتحققات التي لا يستطيع المستودع إثباتها بذاته، لا تفويضًا لتنفيذها تلقائيًا.
