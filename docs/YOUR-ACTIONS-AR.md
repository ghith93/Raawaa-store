ولا توكن، وموصّل GitHub في المنصة غير مدعوم. لذلك لا أستطيع الدفع (push) ولا فتح PR.

**ما لديك:** مستودع عام اسمه `ghith93/agent-team-starter` — لكنه مشروع آخر تمامًا
(أدوات وكلاء، ليس المتجر). **لا ترفع المتجر فوقه**، سيتلف المشروعين معًا.

اختر أحد الخيارين:

### الخيار (أ) — الأسهل: أنشئ مستودعًا جديدًا وارفع ملف ZIP
1. افتح Safari على الآيفون ← `github.com/new`
2. الاسم: `rawaa-store` · الخصوصية: **Private** · **لا** تضف README
3. اضغط **Create repository**
4. في صفحة المستودع اضغط **uploading an existing file**
5. نزّل `dist/rawaa-project-review.zip` من مساحة العمل ← اضغط عليه في تطبيق «الملفات» لفك الضغط
6. في صفحة الرفع اختر **choose your files** ← مجلد `rawaa-project-review` كاملًا ← **Commit changes**

> حجم الرفع من الآيفون قد يتوقف عند الملفات الكبيرة. إن حدث ذلك، ارفع
> `dist/rawaa-site-deploy.zip` بدلًا منه (4.3 ميجابايت فقط، والموقع كامل ويعمل).

### الخيار (ب) — إن أردت الإبقاء على مستودع `Sales` نفسه

بمجرد أن يصبح عامًا أستطيع قراءته، وأدفع الإيداعات الستة إليه، وأعيده خاصًا بعد التأكد.

## الخطوة 3 — معاينة الموقع على آيفونك (3 دقائق)

المعاينة الحيّة تعمل الآن داخل المنصة على المنفذ **8080**. افتحها على الآيفون وتأكد من:
- [ ] الاسم يظهر `RAWAA` و«رواء» بشكل صحيح
- [ ] الصور تُحمَّل بسرعة
- [ ] «إضافة إلى السلة» يعمل، ويظهر الشريط الأسود أسفل الشاشة
- [ ] تغيير طريقة الدفع يغيّر الإجمالي أمامك
- [ ] زر «متابعة الطلب عبر واتساب» يفتح واتساب برسالة كاملة

**إن أردت معاينة على شبكتك المحلية** (لأن هاتفك لا يصل إلى منفذ المعاينة):
```bash
# على جهاز في نفس شبكة الواي فاي
cd rawaa-site-deploy && python3 -m http.server 8080 --bind 0.0.0.0
# ثم من الآيفون: http://<IP-الجهاز>:8080
```

## الخطوة 4 — الاستضافة (15 دقيقة، مجانية، وبقرارك)

الموقع **ثابت بالكامل**: HTML + CSS + JS + صور. لا خادم ولا قاعدة بيانات ولا باك-إند.

### الخيار الأول: GitHub Pages (مجاني، بلا بطاقة)
1. ارفع المشروع (الخطوة 1)
2. `Settings` ← `Pages` ← Source: **Deploy from a branch** ← `main` / `root` ← Save
3. بعد دقيقتين سيظهر رابط مثل `https://ghith93.github.io/rawaa-store/`

### الخيار الثاني: Netlify (سحب وإفلات، بلا سطر أوامر)
1. `app.netlify.com/drop`
2. اسحب `dist/rawaa-site-deploy.zip` (أو المجلد المفكوك) إلى الصفحة
3. تحصل على رابط فورًا — ويمكنك ربط نطاق لاحقًا

### الخيار الثالث: Cloudflare Pages
مناسب إن أردت نطاقًا خاصًا لاحقًا. يحتاج حسابًا فقط.

> بعد النشر: افتح `sitemap.xml` وأضف النطاق الحقيقي مكان التعليق، ثم افتح `robots.txt`
> وتأكد من سطر `Sitemap:`.

## الخطوة 6 — تسجيل النشاط التجاري (قرارك أنت)

إن كان البيع تجاريًا في سوريا فقد تحتاج تسجيلًا. **لا أعرف التفاصيل القانونية ولا أستطيع
التحقق منها**، ولن أخترعها. اسأل محاسبًا أو جهة التسجيل المختصة. ما أستطيع تأكيده:
- الموقع لا يدّعي تسجيلًا ولا شهادة ولا اعتمادًا.
- سياسة الخصوصية في `privacy.html` مكتوبة كـ **مسودة** وتحتاج مراجعة قانونية قبل الإطلاق.
