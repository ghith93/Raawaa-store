# خارطة أدوات رواء المفتوحة والمجانية

تاريخ البحث: 2026-10-29. هذه قائمة منتقاة، وليست حصرًا لكل مشاريع GitHub أو ضمانًا لتفوّق تجاري. الأسعار والحدود وشروط الاستخدام تتغير؛ تحقق منها قبل تفعيل أي خدمة. ترخيص الكود لا يعني أن الاستضافة أو التشغيل مجانيان. لم نفعّل أي خدمة جديدة في هذه الجولة.

## القرار التنفيذي

نحتفظ بالمتجر الثابت وطلب واتساب بدل إعادة بنائه بمنصة تجارة كاملة: منتج واحد وسلة محلية لا يبرّران خادمًا وقاعدة بيانات وتكاليف صيانة إضافية. الأولوية هي صحة الطلب ووضوح التوصيل والخصوصية والقياس، لا كثرة الأدوات. يلي ذلك تحسين الوصول العضوي واختبار الرسائل الإعلانية إذا وافق المالك على الميزانية. لا يوجد دليل حالي على مبيعات أو تحسن تحويل.

| الأولوية | المشروع أو الخدمة | القرار والفائدة | التكلفة والمخاطر |
|---|---|---|---|
| الآن | [Playwright](https://github.com/microsoft/playwright) — Apache-2.0 | موجود لاختبار رحلات الزائرة على المتصفحات، السلة واتساب والجوال وحالات الانقطاع. | مجاني مفتوح المصدر؛ النتائج المختبرية لا تثبت المبيعات. |
| الآن | [axe-core](https://github.com/dequelabs/axe-core) — MPL-2.0؛ [Lighthouse](https://github.com/GoogleChrome/lighthouse) — Apache-2.0 | موجودان للإتاحة والأداء؛ مع مراجعة بشرية واختبار شاشة صغيرة. | مجانيان؛ الفحوص الآلية لا تكشف كل مشكلات الإتاحة. |
| الآن | [ESLint](https://github.com/eslint/eslint)، [html-validate](https://github.com/html-validate/html-validate) | أدوات تدقيق مدمجة. حافظ على القفل وفحص التبعيات والبوابات الحالية. | مفتوحة المصدر؛ لا داعي لتكرارها بأدوات تحقق تؤدي المهمة نفسها. |
| الآن | [Cloudflare Pages](https://developers.cloudflare.com/pages/platform/limits/) | إبقاء الاستضافة الحالية للموقع الثابت. الخدمة المستضافة ليست مشروعًا مفتوح المصدر؛ [Wrangler](https://github.com/cloudflare/workers-sdk) مفتوح المصدر. | الخطة المجانية تشمل 500 بناء شهريًا وبناءً متزامنًا واحدًا؛ الدوال تخضع لحدود Workers المنفصلة. تحقق من الشروط وتوفر الخدمة في سوق الزبائن. |
| بعد التجهيز | [Umami](https://github.com/umami-software/umami) — MIT | مرشح لقياس الصفحات وأحداث عامة مثل اختيار الحجم وفتح واتساب، دون أسماء أو أرقام أو نص الرسائل. | [Cloud Hobby](https://umami.is/pricing): موقع واحد و100 ألف حدث/شهر واحتفاظ 6 أشهر حسب الصفحة الحالية؛ API وMCP مذكوران في Pro لا Hobby. الاستضافة الذاتية مجانية كبرنامج لكن تحتاج بنية وصيانة. يلزم حساب ومراجعة خصوصية وتحقيق التوافق قبل التفعيل؛ لا يُعد فتح واتساب طلبًا مؤكدًا. |
| عند الحاجة الفعلية | [Supabase](https://github.com/supabase/supabase) | قاعدة بيانات اختيارية لإدارة حالات الطلبات لاحقًا، لا بديل عن واتساب أو إثبات وصول الرسائل. | [الخطة المجانية](https://supabase.com/pricing): قاعدة 500 MB ومشروعان نشطان، مع إيقاف بعد أسبوع من الخمول ولا نسخ احتياطية آلية في الخطة؛ يلزم أمن وصلاحيات RLS ونسخ واستعادة واختبار بيانات شخصية قبل الإنتاج. لا نستخدمها لحفظ محادثات العملاء افتراضيًا. |
| لاحقًا فقط | [Medusa](https://github.com/medusajs/medusa) | خيار يُقيّم إذا زاد الكتالوج وأصبح مخزون وطلبات ودفع حقيقي ضرورية. | يتطلب تشغيلًا وقاعدة بيانات وتكاملات وصيانة؛ GitHub يعرض NOASSERTION للترخيص، لذا افحص تراخيص كل حزمة وشروط الخدمات قبل التبني. ليس اختيارًا الآن. |
| غير معتمد | [n8n](https://github.com/n8n-io/n8n)، [NocoDB](https://github.com/nocodb/nocodb)، [Chatwoot](https://github.com/chatwoot/chatwoot) | أدوات محتملة للأتمتة والجدولة أو خدمة العملاء، لكن لا يُفترض أنها جميعًا مفتوحة المصدر بالكامل أو أن كل وظائفها مجانية. | GitHub يعرض NOASSERTION؛ قد تشمل تراخيص عادلة/تجارية أو مكونات بشروط مختلفة. يلزم تدقيق ملفات الترخيص والمنتج والاستضافة والخصوصية والجدوى قبل أي اعتماد. |

تراخيص GitHub المذكورة في الجدول تحققت من بيانات المستودعات عبر واجهة GitHub؛ لا تحل محل قراءة الترخيص والتبعيات قبل التوزيع. سجل الأدوات الموجودة وتفاصيل إزالتها في `OPEN-SOURCE-AUDIT.md`، وقد يختلف عن حالة التشغيل الحالية ويحتاج تحققًا دوريًا.

## الموصلات والإدارة

- **GitHub**: متاح من بيئة العمل لإدارة الشفرة والفحوص؛ لا يعني ذلك وصولًا مباشرًا لكل خدمات النشر. [GitHub Actions](https://docs.github.com/en/actions/concepts/billing-and-usage) مجاني للمستودعات العامة على العدّاءات القياسية؛ الخاص له حصة وخارجها قد تُفرض رسوم. لا نغيّر إعدادات الفوترة أو نفعّل خدمات مدفوعة.
- **Google Drive وNotion وSupabase**: موصلاتها مفعّلة في هذه المحادثة. تفعيل الموصل لا يثبت وجود مشروع مناسب أو صلاحية استخدامه أو جاهزيته؛ لم تُنشأ قواعد بيانات أو تُنقل بيانات أو تُغيّر صلاحيات.
- **Meta/WhatsApp**: لا يوجد موصل معلن لهما في هذه الجلسة. روابط واتساب الحالية لا تمنح وصولًا إلى صندوق الوارد أو قدرة على تأكيد الطلبات، وواجهة WhatsApp Business API الرسمية قد تتطلب حسابًا وتحققًا ورسومًا وشروطًا حسب الخدمة والسوق. لا نستخدم أدوات تسجيل دخول أو إرسال غير رسمية. أي تكامل رسمي يُدرس عند الحاجة والتحقق من الأسعار والبلد.
- **التحليلات والإعلانات**: مفتاح Facebook Pixel في `js/config.js` فارغ؛ لا نفعّله أو نرسل بيانات إلى Meta دون الإعداد القانوني ومراجعة الخصوصية والموافقة المطلوبة. Conversions API ليس وسيلة لتجاوز الموافقة. استخدام مصدر ووسيط ومحتوى UTM في رابط الحملة لا يعني أن البيع اكتمل.

## خطة تنفيذ مرتبة

1. التحقق العملي من الموقع وسلة الهاتف، سلامة الروابط والرسالة والأسعار والتوصيل ومراقبة النشر، دون إرسال طلب حقيقي. معالجة الأعطال أولًا.
2. إعداد خطة قياس محدودة: زيارات، اختيار حجم، فتح السلة وفتح واتساب؛ ثم فصل محادثة مستلمة وطلب مؤكد وتسليم فعلي وبيع عن نقرات الموقع. لا نعد الأخير إلا من سجل موثوق ومصرح به. البدء بـ Umami مرهون بالحساب ومراجعة الخصوصية وعدم تجاوز الحصة.
3. تحسين المحتوى ومحركات البحث وصفحات الهبوط ومواد فيسبوك العضوية باختبارات؛ كل ادعاء عن التركيبة أو النتيجة أو المخزون والسياسات يحتاج مصدرًا أو تأكيدًا. اعتماد الصور التصميمية مع توضيحها.
4. إعداد قالب تشغيلي بسيط لتتبع الطلبات دون بيانات شخصية إلى أن تتوفر حاجة مؤكدة لتخزينها آمنًا. لاحقًا فقط تقييم Supabase مع RLS والنسخ والاحتفاظ المحدود وخطة استعادة؛ عدم جعل الطلب معتمدًا على قاعدة قد تتوقف في الخطة المجانية.
5. إذا أراد المالك إعلانًا: إعداد مقترح جمهور ومواد وروابط UTM ومؤشرات قياس؛ لا إطلاق ولا إنفاق إلا بعد موافقة منفصلة على الميزانية. اختبار التعلم دون ادعاء أن عدد النقرات مبيعات.

## حدود المسؤولية

يمكن للوكيل البحث وتطوير الموقع واختباره والعمل على الخدمات المتاحة عند وجود الصلاحيات. لا يعمل باستمرار خارج الجلسات ولا يستطيع ضمان المراقبة أو الرد على الزبائن أو الشحن دون أنظمة وصلاحيات فعلية. سيبقى تأكيد بيانات المنتج والتوصيل والسياسات وتنفيذ الطلبات والقرارات المالية عند المالك أو من يفوضه. لا تُطلب كلمات مرور أو رموز سرية في المحادثة.
