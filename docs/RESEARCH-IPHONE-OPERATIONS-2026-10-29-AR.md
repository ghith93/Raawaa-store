# أدوات رواء والتشغيل من آيفون — 29 أكتوبر 2026

## النتيجة العملية

الهدف تشغيل المتجر والطلب من الهاتف بتكلفة صفرية قدر الإمكان. لا يمكن حصر جميع مستودعات GitHub أو ضمان أن الخدمة المجانية ستبقى كذلك. هذه مراجعة انتقائية لمصادر ومشاريع مرتبطة بالمشكلة، وليست تدقيقًا أمنيًا للكود أو اختبارًا للإنتاج. لا يُثبت إعلان مستودع أنه آمن أو مجاني التشغيل. لا نُثبت مشروعًا لمجرد وجوده.

## ماذا نعمل الآن؟

1. طلب السحب [#39](https://github.com/ghith93/Raawaa-store/pull/39) يجمع تحسين مراقبة الأسعار والتوصيل وإعداد تنبيه GitHub. الفحوص الآلية على الفرع ناجحة وفق GitHub عند المراجعة، لكنه لم يُدمج أو يُنشر بعد. التنبيه لم يُختبر في الإنتاج، ويحتاج صلاحية إنشاء Issues وإعدادات إشعار مناسبة. لا يمنع تأخير GitHub أو تعطيل الجداول بعد الخمول.
2. عند جاهزية النشر، نفحص وصول التنبيه على الهاتف بدل افتراضه، ونُبقي الموقع وطلب واتساب مستقلين عن أداة التحليلات. إذا تعذرت الصلاحيات نطلب من المالك الموافقة عبر واجهة الخدمة وليس إرسال سر في المحادثة.
3. للقياس نختار أداة واحدة بعد التحقق من الحساب وشروط السوق والخصوصية، ونقيس فتح واتساب منفصلًا عن الرسالة الفعلية والطلب المؤكد والتسليم. Meta Pixel لا يزال غير مهيأ؛ لا نفعّله دون مراجعة الخصوصية والموافقة المطلوبة.
4. إعداد محتوى عضوي ومقترحات إعلانات وروابط حملات دون إرسال أو إنفاق تلقائي. نشر المحتوى وربط Meta يحتاجان حسابًا وصلاحيات رسمية وتحققًا من شروط المنصة.
5. بعد اتضاح أحجام الطلبات الفعلية، نقرر إن كانت إدارة مخزون أو قاعدة بيانات مبررة. لا نجمع بيانات الزبائن أو ننقلها إلى مستودع عام.

## ما يلزم من الآيفون فقط

- يمكن متابعة المتجر والطلبات من Safari وواتساب، دون حاسوب أو تثبيت بيئة برمجة.
- [GitHub Mobile وإعداد الإشعارات](https://docs.github.com/en/subscriptions-and-notifications/get-started/configuring-notifications) خيار لإشعارات GitHub؛ تختلف أنواع إشعارات الدفع عن إعدادات متابعة المستودع، ولا نَعِد بوصول تنبيه قبل اختباره.
- لا حاجة إلى أن يحرر المالك الشفرة. عند ضرورة موافقة على ربط حساب، تتم من واجهة الخدمة، ولا تُرسل كلمات المرور أو رموز التحقق أو التوكنات عبر المحادثة.
- نحتاج معرفة ما إذا كان رقم المتجر يستخدم WhatsApp Business، لكن لا يلزم نقل الرقم إلى API الآن. [Meta توضح](https://developers.facebook.com/documentation/business-messaging/whatsapp/embedded-signup/onboarding-business-app-users/) أن الربط بـ Cloud API قد يغيّر ميزات أو يفصل أجهزة مرتبطة؛ لا نجريه دون خطة وتحقق.

## حدود الأتمتة

الأتمتة على GitHub يمكنها العمل خارج جلسة الوكيل بشرط الصلاحيات وموثوقية الخدمة؛ الوكيل نفسه ليس خدمة دائمة، ولا يستطيع قراءة رسائل واتساب أو إدارة حساب Meta ما لم يتوفر اتصال رسمي مخوّل. لا نضمن تفوقًا عالميًا أو زيادة مبيعات قبل قياس نتائج حقيقية.
