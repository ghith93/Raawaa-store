# بحث مشاريع GitHub الشائعة والمتصدّرة لرواء

**فحص 29 أكتوبر 2026**. المطلوب متجر عربي خفيف لمنتج واحد، طلب عبر واتساب، إدارة من آيفون، وتكلفة تشغيل صفرية قدر الإمكان. هذه عينة منتقاة وليست جميع GitHub أو مراجعة أمنية للكود. النجوم عدد تراكمي وليست نموًا حديثًا أو دليل جودة. لا تدل كثرة النجوم ولا `pushed_at` وحدهما على أمان المنتج أو جاهزيته؛ التاريخ المذكور آخر دفع كما عرضته API وليس تاريخ إصدار مستقر. الأعداد تتغير.

## المنهج

- بحث GitHub API عن `ecommerce`, `web analytics`, `social media scheduling`, `customer support chat`, `monitoring uptime`, `marketing automation`, `inventory management`, `workflow automation`، بحد أدنى 500 أو 1000 نجمة وترتيب إجمالي النجوم، وعرض ست نتائج لكل استعلام. هذه نتائج أولية لا حصر ولا ترتيب مطلق لكل المشاريع بسبب صياغة البحث.
- للترند الحقيقي نظرنا إلى [GitHub Trending الشهري لـ JavaScript](https://github.com/trending/javascript?since=monthly): ظهر `coreyhaines31/marketingskills` مع **5,528 نجمة خلال الشهر** وقت القراءة المباشرة. هذا نافذة شهرية، وليس عدد نجوم اليوم، ويختلف عن العدد الإجمالي أدناه. صفحات الترند متغيرة وليست ضمانًا للنتائج مستقبلًا.
- تحققنا من بيانات المشروع عبر `gh api repos/OWNER/REPO`: النجوم، الترخيص المكتشف، الأرشفة وآخر دفع. للمشاريع غير القياسية أو متعددة التراخيص لا تكفي `NOASSERTION` للحكم بترخيص جميع الأجزاء. قُرئت أجزاء من ملفات `copywriting` و`seo-audit` في marketingskills، ولم تُثبّت. معلومات المتطلبات والخطط من الوثائق الرسمية المرتبطة. لم يُشغّل أو يُدقَّق الكود الخارجي أمنيًا ولم تُفعَّل أدوات أو تتبعات جديدة.

## خطة الاستعمال المرتبة

1. **الآن — فحوص الموقع والشراء**: مواصلة Playwright وaxe وLighthouse القائمة. استخدم أفكار marketingskills المراجَعة كمبادئ: وضوح الفائدة، خطوة رئيسية واضحة، اعتراضات حقيقية، وإسناد كل ادعاء. لا تغير سعرًا، ولا تختلق نتائج أو مراجعات، ولا تشغّل نصوصًا من المستودع.
2. **الآن — الاعتمادية**: الإبقاء على مراقبة GitHub التي نفحص بها الأحجام والأسعار والدفع، والتحقق من وصول تنبيه فعلي إلى هاتف المالك. Upptime مصدر أفكار لا يحل قصور جدولة GitHub ولا يلزم تثبيته.
3. **بعد مراجعة الخصوصية والحساب**: تجربة Umami Hobby دون ترقية أو بطاقة إن أمكن وحسب الشروط، مع تتبع أحداث إجمالية محدودة (زيارة، اختيار، فتح سلة، فتح واتساب) وعدم إرسال رقم أو اسم أو محتوى رسالة. قراءة من الهاتف ممكنة عبر المتصفح، لكن لا نعد الوصول أو التوافق مثبتًا حتى يُختبر. فتح واتساب ليس محادثة أو بيعًا.
4. **محتوى عضوي**: إنتاج مسودات عربية ومراجعتها وفق بيانات المنتج؛ لا ربط Meta أو نشر آلي أو ادعاء أن النشر حدث قبل وجود صلاحيات واختبار. الإعلان المدفوع يحتاج موافقة منفصلة على الميزانية.
5. **عند حجم عمل مبرر**: مقارنة Postiz وChatwoot وInvenTree بمسار أبسط، واختبار الأمان والتراخيص والحصص والأجهزة والنسخ والاسترجاع قبل أي ربط. لا تُجمع بيانات الزبائن في المستودع العام.

## ما لم يُنجز

لم يُفعّل Umami أو أي مشروع اجتماعي أو خدمة عملاء جديدة. لم تُفحص جميع المشاريع، أو يُجرَ تدقيق أمني شامل، أو تُثبت علاقة بين النجوم وزيادة المبيعات. لا وكيل حاضر بشكل دائم خارج الجلسة. لم تُرسل رسائل أو تُشغّل إعلانات أو تتحمل ميزانية في هذه الجولة.
