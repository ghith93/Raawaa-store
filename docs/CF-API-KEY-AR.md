# المفتاح العام — وصول كامل بلا نقص

> **طلبك:** صلاحيات كاملة + القدرة على إنشاء توكنات.
> **هذا هو الطريق الوحيد الذي يحققه حرفيًا.** لا توكن مخصص يستطيع ذلك.

---

## الرابط

```
https://dash.cloudflare.com/profile/api-tokens
```

---

## الخطوات

| # | الخطوة |
|---|--------|
| 1 | افتح الرابط |
| 2 | انزل إلى أسفل الصفحة — قسم **API Keys** (تحت قسم Tokens) |
| 3 | بجانب **Global API Key** اضغط **View** |
| 4 | سيطالبك بكلمة مرور Cloudflare — أدخلها |
| 5 | سيظهر مفتاح طويل — **انسخه** |
| 6 | أرسل لي في المحادثة: **البريد** + **المفتاح** |

انسخ الاثنين معًا. المفتاح العام يعمل فقط مقترنًا ببريد الحساب.

## ما يمنحه هذا المفتاح

| | الحالة |
|---|---|
| الصلاحيات | **كل شيء، بلا استثناء، بلا نقص** |
| النطاقات | كل الحساب + أي نطاق جديد |
| إنشاء توكنات | **نعم** — ما طلبته بالضبط |
| إنشاء حسابات فرعية | نعم |
| الحذف والتعديل | نعم، على كل شيء |
| تاريخ الانتهاء | **لا ينتهي** |
| قابلية التقييد بنطاق | **لا** — هذا هو الفرق الوحيد عن التوكن |

---

## ⚠️ ثلاثة أمور يجب أن تعرفها قبل اللصق

**1. المفتاح + البريد = الحساب كله.**
من يملكهما يستطيع حذف كل مشاريعك — `gaiooth-council-gateway` و`runtime`
و`scheduler` و`rawaa-store` — بلا استرجاع. سأتعامل معه على هذا الأساس.

**2. لا يمكن تقييده بـ IP ولا بنطاق.** لا توجد وسيلة لتضييق نطاقه.

**3. فعّل التحقق بخطوتين إن لم يكن مفعّلًا.**
```
https://dash.cloudflare.com/profile/authentication
```
المفتاح العام يعمل للـ API بلا رمز تحقق، لكن 2FA يحمي **لوحة التحكم**
من الإيميل+كلمة المرور المسروقة. لا يحمي المفتاح نفسه — لكنه يقلّص
الطريق الأسهل للاختراق.

## ما سأفعله فور الاستلام

| # | الخطوة | الأداة |
|---|--------|--------|
| 1 | تحقق من الهوية والوصول | `scripts/cf_api.py` |
| 2 | إنشاء `rawaa.eu.org` | `--stage zone` |
| 3 | إرسال سطرَي خوادم الأسماء إليك | — |
| 4 | **إنشاء توكن مقيّد لك اليوميات** | `POST /user/tokens` |
| 5 | ربط النطاق بعد تفعيله | `--stage attach` |
| 6 | تبديل الروابط + QR + نشر + اختبار | `--stage urls` |

### الخطوة 4 مهمة — اقرأها

سأستخدم المفتاح العام **مرة واحدة** لإنشاء توكن مخصص واسع لكن مقيّد
بحسابك، وأعطيك إياه لتحفظه عندك. بعدها:

- **المفتاح العام** يبقى في مكانه عندك، لا يعود للمحادثة إلا عند حاجة نادرة
- **التوكن المقيّد** هو ما أستخدمه في كل نشر يومي

هذا يقلّص عدد المرات التي يظهر فيها المفتاح الرئيسي. لن أخزّن أيًّا منهما
في أي ملف — لا أنا ولا المشروع.

## الحماية التي ألتزم بها بلا استثناء

| نعم ✅ | لا ❌ |
|--------|-------|
| متغيّر بيئة لسطر واحد ثم إزالته | كتابته في ملف أو log |
| العمل على `rawaa-store` فقط | لمس `gaiooth-*` إطلاقًا |
| التحقق قبل كل حذف | أي حذف بلا نسخة احتياطية |
| إبلاغك بكل تغيير يمسّ الحساب | تجربة شيء «لنرى ماذا يحدث» |

**مشاريعك الثلاثة الأخرى محصّنة.** لن أرسل أمرًا واحدًا يذكر أسماءها.
ولو احتجت صلاحية تخصّها، سأسألك أولًا.

## الطريقان — الفرق الحقيقي

| | مفتاح عام | توكن مخصص |
|---|---|---|
| صلاحيات كاملة | ✅ | جزئيًا فقط |
| **إنشاء توكنات** | ✅ | ❌ **مستحيل** |
| إنشاء نطاق | ✅ | ✅ بصلاحية Zone:Edit |
| التقييد بنطاق | ❌ | ✅ |
| الانتهاء التلقائي | ❌ | ✅ |

**لهذا اخترت أن أسألك بدلًا من أن أقرر:** ما طلبته (إنشاء توكنات) يتطلب
المفتاح العام، وهو غير قابل للتقييد. وافقْتَ على المخاطرة صراحةً،
وسجّلتها هنا.

## إن أردت التراجع لاحقًا

```
https://dash.cloudflare.com/profile/api-tokens
```
قسم **API Keys** ← **Global API Key** ← **Change** → مفتاح جديد فورًا،
والقديم يتوقف في اللحظة نفسها. لا يحتاج حذفًا.
