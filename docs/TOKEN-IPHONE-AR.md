# توكن GitHub من الآيفون — دقيقتان

> **لماذا لا أستطيع إنشاءه؟** GitHub لا يسمح بإصدار توكن إلا من داخل حساب مسجَّل دخوله.
> لا توجد واجهة برمجية تُصدر توكنات — وهذا إجراء أمني مقصود في GitHub نفسه.
> لذلك هذه الخطوة الوحيدة التي تمرّ بك. لا يوجد بديل تقني.

## الخطوات

1. افتح **Safari** وسجّل الدخول إلى `github.com` بحساب `ghith93`.
2. اذهب مباشرة إلى:
   `https://github.com/settings/personal-access-tokens/new`
3. املأ الحقول (انسخ القيم كما هي):

   | الحقل | القيمة |
   |---|---|
   | **Token name** | `rawaa-deploy` |
   | **Expiration** | `30 days` |
   | **Repository access** | ✅ `Only select repositories` ← اختر `Raawaa-store` |
   | **Permissions → Repository permissions → Contents** | `Read and write` |
   | بقية الصلاحيات | اتركها `No access` |

4. اضغط **Generate token** في أسفل الصفحة.
5. انسخ النص الذي يبدأ بـ `github_pat_…` — **يظهر مرة واحدة فقط**.
6. الصقه في رسالة هنا. سأستخدمه وأرفع الإيداعات المعلَّقة فورًا.

## ملاحظات

- **لا تشاركه في أي مكان آخر** — لا صور، لا مجموعات، لا محادثات ثانية.
- الصلاحية محدودة بمستودع واحد و«Contents» فقط → لا يستطيع حذف المستودع ولا تغيير الإعدادات.
- بعد انتهاء الرفع أطلب منك **Revoke** من نفس الصفحة إن أردت؛ الإيداعات تبقى كما هي.
- بديل بلا توكن إطلاقًا: افتح `github.com/ghith93/Raawaa-store` من Safari → `Add file` →
  `Upload files`، لكنه أثقل من إعطائي توكن لمدة 30 يومًا.
