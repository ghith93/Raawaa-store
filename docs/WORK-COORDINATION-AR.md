## 4. قواعد منع التعارض

1. افحص قائمة PRs والفروع والـSHA قبل إنشاء فرع أو تعديل ملف.
2. اكتب فقط ضمن المسارات المصرح بها في المهمة.
3. لا تعِد استخدام فرع وكيل آخر ولا تدفع إلى `main`.
4. إذا ظهر أن الملف مملوك لمهمة أخرى، أوقف الكتابة على ذلك الملف وأبلغ عبر #464.
5. استخدم PRs صغيرة ذات هدف واحد، واربط كل PR بالمهمة الأم.
6. لا تُحدّث فرعًا مفتوحًا بطريقة تمحو commits أو تغييرات وكيل آخر.
7. بعد كل تغيير، اذكر SHA والملفات والاختبارات ونتائج CI وأي حدود لم يتم التحقق منها.
