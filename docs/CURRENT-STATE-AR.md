## ٣. ما يعمل وما لا يعمل — بصراحة

**يعمل:**
- تصفح الموقع والأحجام والأسعار وسلة مرجعية ورسالة واتساب معبّأة.
- العمل دون اتصال بعد زيارة مكتملة (PWA) مع إرشادات تثبيت.
- بوابات الفحص المحلية: `gates:offline` **249/249**، `check-site` **524/0**، `ref-audit` **29/0**، البناء **177 ملفًا / 14 MB**.

**لا يعمل / غير مفعّل:**
- **لا بوابة دفع.** لا تُخصم أموال ولا تُعالج بطاقات.
- **لا استقبال طلبات تلقائي.** فتح واتساب **لا يثبت** إرسال رسالة ولا وصولها ولا تسجيل طلب.
- **لوحة المالك غير موصولة** باستقبال طلبات حقيقي؛ جداول Supabase والهجرات (001→006) موجودة، لكن `005` غير مطبَّقة و`006` مطبَّقة على staging فقط.
- **لا قياس إعلاني فعّال.** البكسل بلا معرّف (`facebookPixelId: ''`) فلا يُحمَّل شيء.
- **لا مخزون حي.** التوفر يُؤكَّد في واتساب.

## ٤. حالة المراقبة والـCI

| السير | الجدولة | الحالة |
|---|---|---|
| Site checks | push + PR | يعمل|
| Deploy | بعد نجاح Site checks | يعمل |
| Uptime | كل ٦ ساعات | **كان يفشل ٧ مرات (٤–٦ نوفمبر) — أُصلح السبب في هذه الجولة** |
| Outbox scheduler | كل ٥ دقائق | يتخطى بصمت إن لم يُضبط السرّ (سلوك مقصود ومعلن) |
| Retention scheduler | يوميًا | لا ينشر: يعتمد على migration 005 غير المطبَّقة |

**سبب عطل المراقبة وأصلحه:** البناء ينشر `config.js` كـJSON، والمراقب كان يقرأه بتعبيرات نمطية تفترض صياغة المصدر. العقد الآن في `scripts/lib/public-config.mjs`، والحارس `scripts/published-config-contract.test.mjs` يشغّل قارئ المراقبة على مخرَج البناء. **التحقق الحقيقي يحتاج تشغيل `uptime` بعد النشر.**

## ٥. الأسرار والمفاتيح

- **لا أسرار في Git.** `.gitignore` يحجب `.env*`, `*.pem`, `*.key`, `secrets/`, `.wrangler/`.
- `owner/settings.mjs` يحمل **مفتاحًا عامًا قابلًا للنشر** فقط (`sb_publishable_…`). لا `service_role`.
- الأسرار الحقيقية في: أسرار GitHub Actions (`CLOUDFLARE_API_TOKEN`, `RAWAA_*`) وأسرار Supabase Edge Functions.
- **ممنوع** لصق أي سرّ في وثيقة أو محادثة أو ملف مصدر.

## ٦. الخطوة التالية — مرتّبة

1. **تحقق من إصلاح المراقبة:** شغّل `uptime` مرة يدويًا (`workflow_dispatch`). إن نجح `تحقق من المحتوى الحيّ` فالعطل أُغلق. ثم أغلق issue #111 و#133.
2. **حماية الفرع إداريًا:** اجعل Site checks وCode quality فحوصًا مطلوبة في إعدادات GitHub. (واجهة GitHub ترفض من التكامل — يحتاج المالك.)
3. **قرار المالك على النطاق:** لا تُضف أنظمة قبل **أول عبوة مبيعة**. النظام الحالي كافٍ للبيع اليدوي عبر واتساب.
4. **مؤجَّل بشرط:** staging معزول → اختبار E2E → تفعيل استقبال الطلبات. هذا لا يبدأ قبل قرار مالك صريح.
5. **اختبار أجهزة:** تثبيت PWA على iPhone وAndroid فعليًا. CI يحاكي ولا يغني.
