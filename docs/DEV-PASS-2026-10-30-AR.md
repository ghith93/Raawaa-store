### ج) إصلاح أداة `purge-css.mjs` نفسها

`@media (prefers-reduced-motion)` و`@media print` قواعد ميتة لأن تعليقًا يسبقها.
النتيجة قبل الإصلاح: كانت ستحذف قواعد **حيّة**. بعد الإصلاح: تقرأ كل المصادر
(7 صفحات + 6 ملفات JS/MJS)، وتُبقي أي بلوك يبدأ بـ`@` بعد تجاهل التعليقات، وأي محدد
فيه حالة تفاعلية أو سمة أو معرّف. أُضيف `--apply` و`--check` (يفشل إن تجاوز CSS الميت 8%).

## 14) اختبار Service Worker الفعلي عند التنقل دون اتصال — الفرع اللاحق

كانت اختبارات Node تحاكي Cache API، بينما اختبار Chromium السابق كان يعيد تحميل `/index.html` ويختبر السلة دون شبكة، ولا يطلب صراحةً جذر الموقع ذي query أو صفحة الخصوصية في السياق غير المتصل. أضيفت تغطية المتصفح لهذه المسارات:

- بعد تثبيت العامل والسيطرة على الصفحة، يقطع اختبار Chromium الشبكة ثم ينتقل إلى `/?utm_campaign=offline-browser-probe`؛ يتحقق أن الصفحة الرئيسية المخزنة تظهر على مسار `/`.

- يطلب أربع صور كبيرة بصيغ AVIF وWebP وJPEG أثناء الانقطاع، ويتحقق بايتًا ببايت من أنها رجعت إلى صور fallback الصغيرة نفسها من CacheStorage.
- استمر اختبار السلة ومجموعها دون اتصال. لا يتغير كود الموقع المنشور ولا الأسعار أو الرسوم.
- محليًا: `npm run gates:offline` نجح (Node 40/40، `check-site` 485/485، ومراجع/أداء/ESLint/HTML validation ناجحة)، و`git diff --check` نظيف.
