> **النطاق:** تدقيق كامل للمشروع (بنية، أصول، أوزان، بوابات، JS ميت، CSS ميت، HTML، SEO،
> إتاحة) ثم تنفيذ الإصلاحات والتحسينات، مع قياس قبل/بعد لكل بند.
>
> **القيود الصريحة في هذه الجلسة:** لا شبكة خارجية (لا يمكن الوصول إلى
> `raawaa-store.pages.dev` ولا تنزيل Chromium)، فلا تشغيل لـ Playwright ولا Lighthouse
> ولا `asset-audit` ولا `perf-budget`. كل ما دون «متحقَّق» أدناه تحقّق **بفحص ثابت**
> (قراءة ملفات + بوابات محلية) وليس بمتصفح. **لم يُنشر شيء.**

## 2) ما نُفِّذ (ومقياسه)

### أ) بوابتان جديدتان تعملان بلا شبكة ولا متصفح

| الملف | ما يفحصه | النتيجة |
|-------|----------|---------|
| `scripts/ref-audit.mjs` | 29 فحصًا: مراجع كل ملف، الخطوط (مفقودة/يتيمة)، قائمة `CORE`، مسارات 404 المطلقة، `noindex` لصفحات التشخيص، JSON-LD مقابل `config.js`، `alt`+`width`+`height` لكل صورة، تكرار المعرّفات، ثوابت التسعير والدفع، إتاحة أساسية، مطابقة `sitemap` | **29 نجاحًا / 0 فشل** |
| `scripts/perf-static.mjs` | ميزانية وزن أول زيارة بالبايت بعد gzip + أكبر صورة | **135.1K** من أصل 175K مسموحة |

ثوابت التسعير التي أصبحت مفروضة آليًا (من `js/config.js` نفسه، لا نسخًا يدويًا):
السعر يزيد مع الحجم · سعر المل يقل مع الحجم (`0.567 > 0.408 > 0.255`) · هامش موجب في أسوأ حالة
(تكلفة 4$ + خصم 10%: `30ml=11.3$ · 50ml=14.36$ · 100ml=18.95$`) · رسوم ومناطق سليمة · رقم واتساب بصيغة دولية.

### ب) إصلاحات

- **404.html:** مسارات مطلقة + زر ثانٍ إلى `/serum` + قاعدة `.notfound-actions`.
- **check.html:** العيّنات صارت من الأصول الحالية (v6) مع تعليق يمنع إضافة اسم غير موجود.
- **setup.html:** `DOCTYPE` كبير + `type="button"` و`type="text"` → **0 أخطاء**.
- **حذف وزن الخط غير المستعمل:** ملف 22.4KB + كتلة `@font-face` + مدخله في `sw.js`.
- **حذف المسار الميت من `cart.js`:** `buildProductCard`, `buildPicture`, `renderProducts`,
  `el.grid` (155 سطرًا). تحقّق: `node --check` + ESLint + 469 فحصًا ثابتًا.
- **حذف 58 قاعدة CSS ميتة** عبر أداة `purge-css.mjs` بعد إصلاحها.
- **`_headers`:** إعادة تحقق لكل HTML (`/*.html`, `/serum`) لمنع HTML قديم يطلب أصولًا محذوفة،
  و`noindex` لـ`/check.html` و`/setup.html`.
- **`robots.txt`:** منع فهرسة `check.html`, `setup.html`, `owner/`.
- **`serum.html`:** `preload` لصورة أول شاشة بنفس `sizes` المطابقة (منع طلبين لنفس الصورة).
- **`check-site.mjs`:** حد وزن الخطوط 100KB → **75KB** (قفل التحسين).
- **CI:** `code-quality.yml` و`site-checks.yml` يشغّلان البوابتين الجديدتين؛
  و`html-validate` صار يفحص كل الصفحات بما فيها `setup.html` و`check.html`.

### ج) إصلاح أداة `purge-css.mjs` نفسها

كانت تقرأ صفحة واحدة (`index.html`) وتتجاهل `serum.html` و`owner/`، وكانت تعتبر
`@media (prefers-reduced-motion)` و`@media print` قواعد ميتة لأن تعليقًا يسبقها.
النتيجة قبل الإصلاح: كانت ستحذف قواعد **حيّة**. بعد الإصلاح: تقرأ كل المصادر
(7 صفحات + 6 ملفات JS/MJS)، وتُبقي أي بلوك يبدأ بـ`@` بعد تجاهل التعليقات، وأي محدد
فيه حالة تفاعلية أو سمة أو معرّف. أُضيف `--apply` و`--check` (يفشل إن تجاوز CSS الميت 8%).

## 4) ما لم يُتحقَّق منه (بصراحة)

1. **لا اختبار متصفح في هذه الجلسة** — لا Playwright ولا Chromium ولا شبكة. الاختبارات
   (141 فحصًا للرئيسية، 168 للمنتج، axe، Lighthouse) **لم تُشغَّل** هنا. يجب تشغيلها في CI
   أو على جهاز فيه متصفح قبل أي نشر.
2. **حذف 58 قاعدة CSS و155 سطر JS** تحقّق ثابتًا (لا اسم مستعمل في أي مصدر)، لكن الشكل
   المرئي النهائي لم يُرَ بعين. لو ظهر أي انزياح بعد النشر فالرجوع بسيط: `git revert`.
3. **صحة `_headers` و`robots.txt`** لا تُختبر إلا على الموقع الحيّ.
4. **لا نشر ولا قياس حيّ** — كل ما فوق داخل المستودع فقط.
