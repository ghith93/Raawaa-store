# Graphify والمراجعة الدورية لرواء

استخدمنا [Graphify](https://github.com/Graphify-Labs/graphify) المفتوح بترخيص Apache-2.0، إصدار `graphifyy==0.9.97`، محليًا لبناء خريطة هيكلية للكود والوثائق وإعدادات المشروع المتتبعة. تعمل القراءة الهيكلية بلا مزود ذكاء اصطناعي أو مفاتيح خارجية. لا تعني روابط الرسم أن المسار يعمل في الإنتاج؛ مثلًا قد يمر الربط عبر ملف اختبار، لذلك يجب مراجعة المصدر واختبار السلوك.

## النطاق والخصوصية

- تُفحص ملفات المصدر المتتبعة بصيغ JavaScript وPython وShell وSQL وMarkdown وJSON وYAML؛ يشمل ذلك اللوحة واختبارات الطلبات وسير عمل GitHub. تحليل Markdown هيكلي للعناوين والروابط، وليس تحليلًا دلاليًا كاملًا.
- تُستخرج هيكليًا معرّفات HTML وأصنافها وروابطها المحلية، وروابط الأصول داخل CSS، دون نسخ النصوص أو معاملات الروابط؛ وتُفهرس أسماء الصور والخطوط فقط. لا يوجد تحليل دلالي للواجهة أو الصور. لا تُفحص الوسائط أو البيانات الثنائية أو سجلات التشغيل أو مجلدات الاعتماديات أو الملفات المخفية الحساسة أو الملفات غير المتتبعة أو قاعدة البيانات.
- تُحفظ الخريطة في `.cache` محليًا، وهي متجاهلة في Git ولا تُنشر في الموقع أو كملف Actions. لا تُقرأ متغيرات البيئة داخل Graphify. لم تُثبَّت ميزات Cloud أو hooks أو موصلات قواعد البيانات.
- استخرج المسح المحلي الأول للنطاق الموسع **1913 عقدة و2785 رابطًا** من 199 ملفًا بنيويًا، مع فهرسة أسماء 166 ملف واجهة وأصلًا وملفًا آخر واستخراج بنية الواجهة محليًا. قد تتغير الأرقام مع تغيّر المشروع، ولا تثبت زيادة المبيعات أو صحة النظام.

## تشغيل محلي

يلزم Python 3.10+ والإنترنت للتثبيت الأول من PyPI فقط:

```sh
python3 -m venv .cache/graphify-venv
.cache/graphify-venv/bin/pip install 'graphifyy[sql]==0.9.97'
bash scripts/graphify-local.sh
```

يظهر مسار `graph.json` في نهاية التشغيل؛ مثلًا يمكن استعمال `graphify explain createCustomerOrderClient --graph PATH`. الاختبارات: `node --test scripts/graphify-select.test.mjs`.

## ما يعمل تلقائيًا وما لا يعمل

يجهّز سير عمل GitHub `Graphify structural review` تشغيل تحليل هيكلي محلي وفحوص الموقع والطلبات يوميًا وعند التغيير إلى `main`، ويمكن تشغيله يدويًا. لا يستعمل نموذجًا لغويًا أو أسرار المشروع، ولا يرسل رسائل، ولا ينشر أو يُصلح التغييرات تلقائيًا. نتائج التشغيل تظهر في GitHub Actions بعد دمج السير على الفرع الافتراضي. GitHub قد يؤخر المهام المجدولة أو يوقفها بعد خمول المستودع؛ لا يوجد ضمان إشعار أو مراقبة على مدار الساعة.

هذا ليس وكيلًا مستقلًا دائمًا. لا يمكن لهذه الجلسة أن تواصل العمل أو تصلح الأعطال وحدها بعد انتهاء المحادثة؛ ولا تزال مراقبة الموقع الأخرى منفصلة عن هذه الخريطة. استقبال الطلبات الحقيقي غير مفعّل.
