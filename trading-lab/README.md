# مدار — مختبر تداول تجريبي

تطبيق مستقل عن متجر رواء، يعمل محليًا في المتصفح، بلا مفاتيح API أو محفظة أو تداول حقيقي أو إرسال بيانات إلى خادم. لا يقدم توصيات مالية. البيانات الافتراضية مولّدة صناعيًا وليست أسعار HYPE.

## التشغيل
من جذر المستودع: `python3 -m http.server 8000 --bind 0.0.0.0` ثم افتح `/trading-lab/`. لا حاجة إلى تثبيت حزم. نفّذ الاختبارات بـ `node --test trading-lab/engine.test.mjs`.

## البيانات
يمكن رفع CSV بحد 5MB والأعمدة بالترتيب `timestamp,price,funding_rate`. الوقت ISO UTC منتهٍ بـ Z؛ الصفوف متصاعدة ومتتالية بفاصل ساعة تمامًا؛ السعر موجب؛ funding معدل عشري محقق للساعة السابقة (0.0001 = 0.01%)، وليس توقع التمويل القادم. مثال:

```csv
timestamp,price,funding_rate
2026-01-01T00:00:00Z,25,0.0001
2026-01-01T01:00:00Z,25.1,0.00012
2026-01-01T02:00:00Z,25.2,0.00011
```

لا توفر هذه النسخة تنزيلًا أو تحققًا من بيانات Hyperliquid. أنت مسؤول عن دقة المصدر ومعنى توقيت التمويل؛ لا تستخدم سعر إغلاق أو معدلًا لم يكن معروفًا في توقيت القرار.

## نموذج المحاكاة وحدوده
رصيد افتراضي $300 ومركز short اسمي $30. تُفتح الصفقة على سعر الصف الحالي إذا تجاوز تمويل الساعتين السابقتين 0.01%، وتغلق إذا كان تمويل الساعتين السابقتين أقل من 0.005% أو تجاوز السعر 2% من سعر الدخول. يُفرض انزلاق 0.05% ورسوم taker 0.045% لكل دخول وخروج، وتُضاف مدفوعات التمويل قبل اتخاذ القرار لكل مركز كان مفتوحًا في الساعة السابقة. تغلق المراكز المتبقية في آخر صف. وقف الخسارة يُفحص بالأسعار الساعية فقط، لذا قد يحدث بسعر أسوأ؛ والانزلاق ثابت افتراضي وليس قياسًا حقيقيًا. قد يعاد الدخول في الصف نفسه بعد الوقف إذا بقيت الإشارة إيجابية. تشمل القيمة الربح والخسارة غير المحققين؛ لا تحاكي التصفية، عمق السوق، التنفيذ الجزئي، الفجوات الداخلية أو عدم توفر المنصة. ليست نتائج الباك تست ضمانًا أو تقديرًا موثوقًا للربح الحي. لا وجود لتداول حقيقي أو مراقبة مستمرة أو Telegram في هذا النموذج.
