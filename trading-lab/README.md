# مدار — مختبر تداول تجريبي

تطبيق مستقل عن متجر رواء، يعمل محليًا في المتصفح، بلا مفاتيح API أو محفظة أو تداول حقيقي. عند طلب البيانات الحقيقية يتصل بخدمة Hyperliquid العامة؛ لا تُرسل ملفات CSV إلى خادم. لا يقدم توصيات مالية. البيانات الافتراضية مولّدة صناعيًا وليست أسعار HYPE.

## التشغيل
من جذر المستودع: `python3 -m http.server 8000 --bind 0.0.0.0` ثم افتح `/trading-lab/`. لا حاجة إلى تثبيت حزم. نفّذ الاختبارات بـ `node --test trading-lab/engine.test.mjs`.

## البيانات
يمكن رفع CSV بحد 5MB والأعمدة بالترتيب `timestamp,price,funding_rate`. الوقت ISO UTC منتهٍ بـ Z؛ الصفوف متصاعدة ومتتالية بفاصل ساعة تمامًا؛ السعر موجب؛ funding معدل عشري محقق للساعة السابقة (0.0001 = 0.01%)، وليس توقع التمويل القادم. مثال:

```csv
timestamp,price,funding_rate
2026-01-01T00:00:00Z,25,0.0001
2026-01-01T01:00:00Z,25.1,0.00012
2026-01-01T02:00:00Z,25.2,0.00011
```

لا توفر هذه النسخة تنزيلًا أو تحققًا من بيانات Hyperliquid. أنت مسؤول عن دقة المصدر ومعنى توقيت التمويل؛ لا تستخدم سعر إغلاق أو معدلًا لم يكن معروفًا في توقيت القرار.

## نموذج المحاكاة وحدوده
رصيد افتراضي $300 ومركز short اسمي $30. تُفتح الصفقة على سعر الصف الحالي إذا تجاوز تمويل الساعتين السابقتين 0.01%، وتغلق إذا كان تمويل الساعتين السابقتين أقل من 0.005% أو تجاوز السعر 2% من سعر الدخول. يُفرض انزلاق 0.05% ورسوم taker 0.045% لكل دخول وخروج، وتُضاف مدفوعات التمويل قبل اتخاذ القرار لكل مركز كان مفتوحًا في الساعة السابقة. تغلق المراكز المتبقية في آخر صف. وقف الخسارة يُفحص بالأسعار الساعية فقط، لذا قد يحدث بسعر أسوأ؛ والانزلاق ثابت افتراضي وليس قياسًا حقيقيًا. قد يعاد الدخول في الصف نفسه بعد الوقف إذا بقيت الإشارة إيجابية. تشمل القيمة الربح والخسارة غير المحققين؛ لا تحاكي التصفية، عمق السوق، التنفيذ الجزئي، الفجوات الداخلية أو عدم توفر المنصة. ليست نتائج الباك تست ضمانًا أو تقديرًا موثوقًا للربح الحي. لا وجود لتداول حقيقي أو مراقبة مستمرة أو Telegram في هذا النموذج.

## بيانات Hyperliquid وتجربة الشهر
زر السعر يطلب `allMids` للقراءة فقط من WebSocket العام الرسمي، ولا يحتاج حسابًا. زر الباك تست يجلب آخر 720 ساعة مكتملة، باستخدام `candleSnapshot` (إغلاق الشمعة عند بداية الساعة التالية) و`fundingHistory` (الوقت المسجل للتسوية). تستخدم النتائج التمويل السابق عند القرار، ولا تقرأ المستقبل. البيانات الناقصة أو المتباعدة توقف الاختبار بدل ملء الفجوات. حد API في هذه النسخة يجزّئ الفترات إلى 400 ساعة. الإغلاق الساعي ليس بالضرورة السعر المتاح وقت التنفيذ، والتمويل الفعلي يستخدم oracle لا الإغلاق؛ هنا يستخدم الإغلاق كتقريب.

زر «بدء تجربة شهر ورقية» يحفظ وقت البدء للساعة التالية في التخزين المحلي لذلك المتصفح والجهاز؛ وزر التحديث يستعيد الساعات المكتملة من API ويعيد المحاكاة منذ البدء وحتى 30 يومًا. لا تُغلق المراكز تلقائيًا في نهاية كل تحديث للتجربة؛ الرصيد يشمل الربح والخسارة العائمين. هذه **إعادة بناء لاحقة** للنتيجة من التاريخ، لا تسجيلًا مستقلًا حيًا أو بوتًا مستمرًا: لن يعمل شيء عند إغلاق الصفحة، ولا توجد تنبيهات أو مراقبة انقطاعات أو حفظ مستقل. قد تتغير نتيجة الإعادة إذا صحح المصدر بياناته، وفقدان بيانات المتصفح يفقد موعد البدء. استخدم نفس الجهاز والمتصفح ولا تمسح بيانات الموقع. تجربة الشهر تسجل موعد البدء فقط محليًا، لا النتائج أو الصفقات على خادم. الأسعار التاريخية والتنفيذ تقريبيان ولا يثبتان الربح، ووقف الخسارة قد يُفوت حركة داخل الساعة. قد تمنع الشبكة أو خدمة العرض الاتصال؛ لا تستخدم VPN لتجاوز قيود محلية.

المصدر الرسمي: https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint و https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/websocket/post-requests

يُقرّب توقيت تسوية التمويل إلى بداية الساعة إذا تأخر بحد أقصى دقيقة، ويُرفض تكرار التسويات أو غيابها. يُستبعد أحدث إغلاق ساعي احتياطيًا لإتاحة وقت لنشر التمويل. يُجرّب HTTPS الرسمي عند فشل WebSocket؛ قد تمنع الشبكة أو سياسة المتصفح الطريقتين.

## التحليل والبحث
يعرض قسم «لماذا ربحنا أو خسرنا» مكونات صافي النتيجة: حركة السعر بالقيمة المرجعية ناقص الانزلاق والرسوم زائد التمويل. يُقارن إعدادا تمويل ثابتان (دخول 0.01% أو 0.02% بالساعة، خروج 0.005%) مع عدم التداول. تُقسم البيانات زمنيًا 60% و40%، تُغلق المراكز وتُصفّر حالة كل جزء على حدة ويعاد الرصيد إلى $300. لا تُختار الإعدادات أو تُضبط تلقائيًا. تسمية آخر 40% اختبارًا مستقلًا لا تصح إذا عدّلت الفرضيات بعد رؤيته؛ المقارنة استكشافية لا دليلًا إحصائيًا. اختبار الحساسية يضاعف الرسوم والانزلاق وقد يغيّر توقيت الوقف والنتيجة. تنزّل أزرار التصدير النتائج أو البيانات إلى الجهاز.

انظر `RESEARCH-AR.md` للمصادر والقيود والأولويات. لا يتوفر لدى هذا التطبيق تكامل Plugins أو Freqtrade أو خدمة جمع تعمل 24/7.
